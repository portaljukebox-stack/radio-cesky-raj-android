# Rádio Český ráj – Android

Instalační APK pro Rádio Český ráj. Zdroj vysílání: https://portal.juke-box.cz:2020/stream/radioceskyraj

Web: https://www.radioceskyraj.cz · Partner: https://rajoviny.cz

APK se sestavuje automaticky v GitHub Actions. Pro instalaci na Android je určen artefakt `Radio_Cesky_Raj_APK`.

Poznámka: Testovací APK je podepsáno vývojovým klíčem; pro publikaci v Google Play je potřeba samostatné produkční podepisování.
